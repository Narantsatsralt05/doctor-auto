# Doctor Auto: 3D teardown site

Scroll-driven concept site for Доктор Авто Сүлжээ (Doctor Auto Chain). A Ridgeback Wagon 3D model, built with three.js, takes itself apart system by system as you scroll.

- Single self-contained page: `index.html` (three.js and Manrope load from public CDNs)
- Hosted on GitHub Pages from the `main` branch root
